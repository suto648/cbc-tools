# CbC Tools

**自分で作った常駐ツールを、1か所から見て操作するための窓。**

トレイにアイコンが1個、窓が1枚。それだけで
「いまどれが生きているか」「PC 起動時に何が上がるか」が分かります。

ツールそのものは作りません。**登録簿と起動係**です。中身は持ち主のものです。

---

## こういう困りごとのための道具です

Claude と一緒に小さな常駐ツールを作っていくと、こうなります。

- どこのフォルダに作ったか忘れる
- いま動いているのか止まっているのか分からない
- 起動するたびにエクスプローラーを開いて `.bat` を探してダブルクリックする
- PC を再起動したあと、何を上げ直すべきだったか思い出せない

CbC は、それらを 1 枚の窓にまとめます。

---

## 使いはじめる

1. zip をフォルダごと展開する
2. **`CbC起動.bat`** をダブルクリックする
3. トレイにランプが出て、窓が開く

Node.js は同梱しているので、何かを入れる必要はありません。
インターネットにも接続しません。

最初は何も登録されていないので、窓に「まだ何も登録されていません」と出ます。
そこに書いてある手順どおり、自分のツールを登録してください。

**止める** … `CbC停止.bat`、窓の「全部止める」、トレイ右クリック →「全部止めて終了」。
どれも同じで、CbC が起動したツールは止まり、環境は元に戻ります。

デスクトップやタスクバーに置くなら `CbC起動.bat` のショートカットを作ってください。

---

## 自分のツールをつなぐ

**`CONNECT.md` を Claude にそのまま渡してください。** つなぐ作業は代わりにやってもらえます。

> `CONNECT.md` を読んで、`C:\...\my-tool` を CbC に登録してください。
> heartbeat を送る処理も足してください。

手でやる場合の最小手順:

1. `hub\registry.json` の `tools` に 1 件足す
2. ツール側から 2 秒ごとに
   `POST http://127.0.0.1:47821/api/state/<id>` を投げる
   （`{ "level": "ok", "detail": "人が読む一言", "pid": 1234 }`）

見本が `tools\sample-daemon\main.js` にあります（Node・依存なし・約50行）。
Python なら `tools\_shared\cbc.py` に同じものが入っています。

**パスは目印で書いてください。** 絶対パスを書くと、そのPCでしか動かなくなります。

| 目印 | 指す場所 |
|---|---|
| `{CBC}` | CbC Tools を置いた場所 |
| `{TOOLS}` | `{CBC}\tools` |
| `{LOGS}` | `{CBC}\logs` |
| `{HOME}` | あなたのユーザーフォルダ |
| `%VAR%` | 環境変数 |

## トレイのランプの色

| 色 | 意味 |
|---|---|
| 緑 | 全部想定どおり |
| 灰 | 一部だけ動いている（普通の状態）／まだ何も登録していない |
| 橙 | 見ておいた方がいいものがある |
| 赤 | 放っておけないものがある。バルーンが1回出る |

窓では、赤いものは**確認ボタンを押すまで明滅し続けます**。
押しても明滅が止まるだけで、直るまで赤いままです。

**この道具は「黙って正常に見える」ことができないように作ってあります。**
作った発端が「壊れているのに成功と報告するタスクに11日気づけなかったこと」なので、
状態が取れないときに緑にはしません。

## 中身

```
CbC Tools\
  CbC起動.bat              これを押す
  CbC停止.bat              全部止める
  cbc.vbs                  実体の入口（無画面起動。bat から呼ばれる）
  CONNECT.md               自分のツールのつなぎ方（Claude に渡せます）
  hub\
    hub.js                 監督・状態バス・HTTP API（Node 標準ライブラリのみ）
    public\index.html      窓（自己完結・外部読み込みなし）
    registry.sample.json   登録簿の見本
    registry.json          あなたの登録簿（初回起動時に見本からできます）
  tray\                    トレイ常駐と、自動起動の登録／解除
  adapters\probe.ps1       プロセス・タスクを2秒ごとに観測する
  tools\
    _shared\               Python からつなぐための部品
    sample-daemon\         つなぎ方の見本（Node）
  logs\                    CbC と各ツールのログ
  node\node.exe            同梱の Node.js
```

窓は `msedge --app=` で開くので、タブもアドレスバーも無い独立したウィンドウになります。
ポートは `127.0.0.1:47821`（ループバックのみ）。外からは触れません。
他と衝突する場合は、環境変数 `CBC_PORT` で変えられます。

## 自動起動

Windows に登録するタスクは **`CbC-Hub` 1個**だけです
（ログオン20秒後に `cbc.vbs /silent`）。
ツールごとの ON/OFF は窓のトグルで決めます。CbC 自身の ON/OFF は窓の右下です。

```powershell
# 登録 / 解除 / 確認
powershell -ExecutionPolicy Bypass -File "<CbC を置いた場所>\tray\install-autostart.ps1"
powershell -ExecutionPolicy Bypass -File "<...>\tray\install-autostart.ps1" -Remove
powershell -ExecutionPolicy Bypass -File "<...>\tray\install-autostart.ps1" -Status
```

## 困ったとき

- **窓が開かない** … `logs\hub.log` を見る。トレイ右クリック →「窓を開く」で再試行できる
- **トレイが出ない** … `powershell -ExecutionPolicy Bypass -File "tray\tray.ps1"` を直接叩くとエラーが見える
- **ツールが「停止中」のまま** … そのツールのログを窓から開く。
  heartbeat 型は 8 秒報告が無いと停止扱いになる
- **全部止めたのに復活する** … `logs\shutdown.flag` が消えているか確認する
  （トレイがこれを見て自分も畳む仕組み）
- **初回起動で警告が出る** … 署名していないため、Windows が確認を求めることがあります。
  内容はすべてテキストで読める形（.js / .ps1 / .vbs）で入っています。
